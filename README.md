# Whose voice is this?

A voice check for a headset AI agent: from a few seconds of speech, is this the owner or someone else?

- [Report](docs/report.md): approach, answer, how it fails.
- [Whole-day design](docs/design.md): sensors, recorded and cloned voices, what to do when unsure.
- [Run it](docs/run.md): one command repeats every number.
